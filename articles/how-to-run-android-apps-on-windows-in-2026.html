How to Run Android Apps on Windows in 2026

Running Android apps on Windows is finally a first class experience. Microsoft Phone Link works well for messaging and notifications, but for full app access you need an Android subsystem. Here is how to set it up in 2026, including the new options for ARM based Copilot Plus PCs.

The three options for running Android on Windows

Microsoft Phone Link for basic sync. Windows Subsystem for Android is deprecated but still works. Android emulators like BlueStacks and LDPlayer for heavier use. The new ARM native option for Copilot Plus PCs is the future.

Microsoft Phone Link

Phone Link mirrors notifications, calls, messages, and photos from your Android phone to your Windows PC. Recent updates added the ability to use Android apps from your phone directly in a window on your PC. Requires a recent Samsung or Honor phone.

Windows Subsystem for Android (WSA)

Microsoft shipped WSA in 2021 and deprecated it in 2024. It still works on most Windows 11 machines. You can sideload APKs via the Amazon App Store or manually. Performance is decent for non gaming apps.

BlueStacks and LDPlayer

These are full Android emulators that run on Windows. They are optimized for gaming but work for any app. They virtualize ARM on x86 hardware, so performance is lower than native but acceptable. Both are free with ads.

The new ARM native option

Qualcomm Snapdragon X Elite and X2 Elite chips run ARM natively. Microsoft is bringing Android support to these chips. Apps compiled for ARM run at native speed. This is the future of Android on Windows.

Google Play Games for PC

Google now distributes a small selection of Android games officially on Windows. The list is small but growing. Performance is excellent because Google handles the ARM translation in the cloud and streams the result.

Picking the right option

For messaging and notifications only: Phone Link. For running a few specific apps: WSA if it still works, or BlueStacks. For gaming: BlueStacks, LDPlayer, or Google Play Games for PC. For the future: ARM native on Copilot Plus PCs.

Performance tips

Allocate at least 8 GB of RAM to the Android instance. Enable hardware virtualization in BIOS. Use the latest graphics drivers. Close other heavy apps. For BlueStacks, set CPU cores to at least 4 and enable high performance mode.
